PERSONAL TRACKER — Android source project v1.0

Features:
- Dark-themed daily checklist
- Add and delete tasks
- Tick/untick completed tasks
- Daily completion percentage
- Saves today's tasks locally on this phone
- Separate task list per calendar date

IMPORTANT: This ZIP contains Android source code, not a compiled APK.
To get an APK, this project must be compiled using Android Studio or a compatible
Android build environment. Phone-only building can be difficult; we can work
through a free build route next. Do not share passwords or personal data with
unknown online build services.

Application ID: com.personaltracker.app
Minimum Android: 6.0 (API 23)
